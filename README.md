# NJU 统一认证助手

非官方 Edge / Chrome 扩展：保存账号、自动登录南京大学统一身份认证，并自动完成滑块验证。

> 非官方项目，与南京大学无关。自动登录和自动完成滑块可能违反学校规定，请先确认并自行承担风险。

## 功能

- 在本机保存学号/工号和密码，不上传、不同步。
- 打开登录页后自动填充并点击登录。
- 自动完成滑块，默认静默不弹窗。
- 四个开关按依赖执行：**保存密码 → 自动登录 → 自动完成滑块 → 静默完成滑块**。前一项关闭时，后面的会自动关闭并变灰。

## 安装

**Edge**

1. 打开 `edge://extensions`，开启“开发人员模式”。
2. 点击“加载解压缩的扩展”，选择包含 `manifest.json` 的目录。
3. 固定到工具栏。

**Chrome**

打开 `chrome://extensions` → 开发者模式 → 加载已解压的扩展程序。

未上架商店；直接安装 `.crx` 可能被浏览器拦截。

## 使用

1. 打开扩展，填入学号/工号和密码，按需打开四个开关，保存。
2. 访问 `https://authserver.nju.edu.cn/authserver/login`。
3. 四个都打开时会自动填充 → 登录 → 滑块 → 静默完成；没自动执行就点“按设置立即执行”。
4. 修改“自动完成滑块 / 静默完成滑块”后，需要刷新登录页才生效。
5. 滑块失败时，关闭“自动完成滑块”，刷新后手动拖动。

## 隐私

- 账号只保存在本机 `chrome.storage.local`，不上传、无统计。
- **当前版本未做主密码加密**；公共电脑请勿勾选“保存密码”。取消勾选会清除本地密码。
- 扩展只会操作统一认证登录页，不读取其他网站。

## 权限

`storage` 保存账号；`scripting` 填充和点击登录；`declarativeNetRequest` 本地替换滑块脚本；仅申请 `https://authserver.nju.edu.cn/*`。

## 限制

仅支持“账号密码 + 滑块”登录；二维码、动态码不支持。学校改版后可能失效。
